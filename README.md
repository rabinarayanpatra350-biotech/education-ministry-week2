# Education Ministry Internship — Core Responsibilities & Tasks

**Week 2 Task** | Education Ministry Internship, Coimbatore | Rabi Narayan Patra | 27 September 2026

A report documenting the core responsibilities of the intern's position across all six assigned areas — day-to-day administration, policy documentation and record management, citizen applications and grievances, project implementation and monitoring, data collection and report preparation, and government office software — built entirely on verified official data (Lok Sabha answers, PIB releases, the CIC Annual Report 2023-24, the National Scholarship Portal dashboard, the PGI 2.0 report, and UDISE+ 2023-24).

## What each responsibility involves (with the numbers that define it)

| Area | Verified anchor figures |
|------|--------------------------|
| Day-to-day administration | Deadline-driven daily schedule; ~450 schools per District Educational Officer |
| Policy documentation & records | G.O. Ms. No. 151 (9 Sep 2022) as a worked example; Public Records Act 1993; RTI Sec. 4(1)(b) proactive disclosure |
| Citizen applications & grievances | RTI 2023-24: **17.51 lakh requests**, 3.86% rejected, 1.77 lakh first appeals; CPGRAMS 2025-26: **18.34 lakh received, 18.13 lakh disposed, average 14 days** vs. the 21-day limit; NSP 2024-25: **21.55 lakh applications**, ₹2,558.91 crore disbursed |
| Project implementation & monitoring | Samagra Shiksha PAB approvals for Tamil Nadu: ₹3,586 cr (2024-25) → ₹2,734 cr (2025-26) → ₹2,469.4 cr (2026-27); ~₹3,440 cr of the Centre's committed share pending, RTE reimbursements ₹362.8 cr released after a Madras High Court order |
| Data collection & reporting | UDISE+ 2023-24: 14.72 lakh schools, 24.8 crore students, 98.08 lakh teachers; 19.7 crore students with Aadhaar seeding |
| Office software & systems | e-Office, PFMS, GeM, UDISE+, NSP, CPGRAMS, DigiLocker — each mapped to the failure mode it addresses |

## A key monitoring insight

Tamil Nadu's PGI 2.0 score for 2023-24 is **559.2 / 1,000 (Akanshi-1)** — with **learning outcomes at 41.2 of 100** the weakest domain while infrastructure sits near 100. No State reached the top grades; the national performance gap narrowed from 51% to 42%.
